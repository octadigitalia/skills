# Templates e Frameworks - Eugene Schwartz

Frameworks prontos baseados nos princípios de Eugene Schwartz para acelerar sua criação de copy.

---

## Template 1: Análise Pré-Copy

Use este checklist antes de criar qualquer copy:

```
[ ] PRODUTO/SERVIÇO
    - O que é?
    - Quanto custa?
    - Qual o mecanismo único?

[ ] PÚBLICO-ALVO
    - Quem são demograficamente?
    - Qual a situação atual deles?
    - O que os frustra?

[ ] CONSCIÊNCIA (marque um)
    [ ] Totalmente consciente (conhece seu produto)
    [ ] Consciente do produto (sabe que existe solução)
    [ ] Consciente da solução (sabe o resultado que quer)
    [ ] Consciente do problema (sabe que algo está errado)
    [ ] Inconsciente (não identifica problema)

[ ] SOFISTICAÇÃO (marque um)
    [ ] Nível 1 - Mercado virgem (seja o primeiro)
    [ ] Nível 2 - Amplie a promessa (maior, melhor, mais)
    [ ] Nível 3 - Mecanismo único (mostre COMO)
    [ ] Nível 4 - Amplie o mecanismo (mais específico)
    [ ] Nível 5 - Identificação profunda (mostre que entende)

[ ] DESEJOS PROFUNDOS
    - O que eles dizem que querem?
    - O que realmente querem? (motivação emocional)
    - Qual dor evitam?
    - Qual ganho buscam?
```

## Template 2: Estrutura de Sales Letter

### Para Público CONSCIENTE DO PROBLEMA

```
[HEADLINE]
Problema específico + Promessa de solução única
Exemplo: "Por que [PROBLEMA ESPECÍFICO] - E Como [SOLUÇÃO CONTRAINTUITIVA]"

[SUBHEADLINE]
Qualificação de quem é para
Exemplo: "Para [PÚBLICO] que já tentaram [SOLUÇÃO ÓBVIA] e falharam"

[LEAD - Identificação]
Parágrafo 1: Descreva a situação frustrante que vivem
Parágrafo 2: Agite - mostre que não é culpa deles
Parágrafo 3: Apresente que existe um caminho melhor

[AGITAÇÃO]
- Aprofunde a dor
- Mostre o custo de não resolver
- Apresente falsas soluções que não funcionam

[REVELAÇÃO]
"A verdade é..."
- Revele a causa raiz do problema
- Introduza seu mecanismo único
- Explique POR QUE funciona (lógica)

[PROVA]
- Caso de sucesso específico (história)
- Testemunhos
- Dados/resultados
- Garantia

[OFERTA]
- O que está incluído
- Valor percebido
- Preço (com justificativa)
- Bônus
- Urgência/escassez

[CALL-TO-ACTION]
- O que fazer agora
- Elimine fricção
- Último empurrão emocional
```

## Template 3: Estrutura de Sales Letter

### Para Público TOTALMENTE CONSCIENTE

```
[HEADLINE]
Oferta direta + Benefício principal
Exemplo: "[PRODUTO] Agora Com [MELHORIA] - [BENEFÍCIO ESPECÍFICO]"

[LEAD - Direto ao ponto]
Parágrafo 1: O que é + Para quem
Parágrafo 2: Principal benefício
Parágrafo 3: Por que agora

[BENEFÍCIOS]
Lista clara dos 3-5 principais resultados

[CARACTERÍSTICAS → BENEFÍCIOS]
Para cada feature, conecte ao resultado emocional

[PROVA RÁPIDA]
- Testemunhos curtos
- Números de resultado
- Logos/credibilidade

[OFERTA]
- Preço
- O que está incluído
- Garantia
- Urgência

[CTA]
Botão/link direto
```

## Template 4: Formula de Headline

### Nível 1-2 de Sofisticação
```
"Como [RESULTADO DESEJADO] em [TEMPO] Sem [OBJEÇÃO PRINCIPAL]"

Exemplo: "Como Perder 10kg em 90 Dias Sem Passar Fome"
```

### Nível 3-4 de Sofisticação
```
"O [MECANISMO ÚNICO] Que [GRUPO CREDÍVEL] Usa Para [RESULTADO] (Sem [MÉTODO TRADICIONAL])"

Exemplo: "O 'Protocolo de Jejum Intermitente' Que Médicos Usam Para Queimar Gordura (Sem Academia)"
```

### Nível 5 de Sofisticação
```
"Por Que [SITUAÇÃO FRUSTRANTE] - E [REVELAÇÃO CONTRAINTUITIVA]"

Exemplo: "Por Que Você Não Consegue Emagrecer (E Não É Falta de Força de Vontade)"
```

### Headline de Curiosidade
```
"O [ADJETIVO] Segredo de [GRUPO ESPECÍFICO] Para [RESULTADO]"

Exemplo: "O Segredo Contraintuitivo de YouTubers de Milhões Para Viralizar Vídeos"
```

### Headline de Identificação
```
"[GRUPO] Estão [RESULTADO POSITIVO] Enquanto [PÚBLICO-ALVO] Ainda [PROBLEMA]"

Exemplo: "Iniciantes Estão Faturando R$ 10k/mês Enquanto 'Experts' Ainda Quebram A Cabeça"
```

## Template 5: Estrutura de Email de Vendas

### Email 1 - Identificação
```
ASSUNTO: [Pergunta que identifica o problema]

CORPO:
Parágrafo 1: Situação frustrante (identificação)
Parágrafo 2: "Eu sei como é porque..."
Parágrafo 3: "Descobri que o problema não era [CRENÇA ANTIGA]"

CTA: Soft (leia mais, descubra, etc.)
```

### Email 2 - Agitação
```
ASSUNTO: [Consequência de não resolver]

CORPO:
Parágrafo 1: Custo de continuar assim
Parágrafo 2: Por que soluções comuns falham
Parágrafo 3: Existe um caminho melhor

CTA: Apresenta a solução
```

### Email 3 - Solução
```
ASSUNTO: [Como resolver de forma única]

CORPO:
Parágrafo 1: Apresenta mecanismo/produto
Parágrafo 2: Como funciona
Parágrafo 3: Prova (caso de sucesso)

CTA: Oferta
```

### Email 4 - Urgência
```
ASSUNTO: [Último aviso/Tempo acabando]

CORPO:
Parágrafo 1: Recapitula o problema
Parágrafo 2: Recapitula a solução
Parágrafo 3: Urgência real (não fabricada)

CTA: Forte - compre agora
```

## Template 6: Bullet Points Irresistíveis

### Fórmula de Curiosidade
```
[RESULTADO ESPECÍFICO] + [ELEMENTO SURPREENDENTE]

✗ Fraco: "Como ganhar dinheiro"
✓ Forte: "Como um erro de digitação me rendeu R$ 50.000 (e como você pode replicar)"
```

### Fórmula de Prova
```
[NÚMERO ESPECÍFICO] + [CONTEXTO] + [RESULTADO]

✗ Fraco: "Muitos clientes satisfeitos"
✓ Forte: "Por que 847 alunos cancelaram Netflix para pagar este curso"
```

### Fórmula de Mecanismo
```
O [NOME DO MÉTODO] + Que [QUEM USA] + Para [RESULTADO]

✗ Fraco: "Técnica de vendas"
✓ Forte: "O 'Close Reverso' que vendedores tímidos usam para fechar R$ 10k+ sem pitch"
```

## Template 8: Framework PAS (Problem-Agitate-Solve)

### Versão Schwartz Avançada

```
[PROBLEM - Identificação Profunda]
Não apenas "você tem X problema"
Mas: "Você já sentiu [EMOÇÃO] quando [SITUAÇÃO ESPECÍFICA]?"

[AGITATE - Custos Múltiplos]
- Custo financeiro
- Custo emocional
- Custo de tempo
- Custo de oportunidade
- Custo social

[SOLVE - Mecanismo + Prova]
Não apenas "compre X"
Mas: "Eis como [MECANISMO ÚNICO] resolve [CAUSA RAIZ]"
+ Prova de que funciona
```

## Template 9: Escada de Desejos

Use para ir do superficial ao profundo:

```
PRODUTO: [Seu produto]

DESEJO SUPERFICIAL:
O que o cliente DIZ que quer
→ Exemplo: "Quero aprender inglês"

POR QUÊ? (Nível 2)
→ Exemplo: "Para conseguir promoção"

POR QUÊ? (Nível 3)
→ Exemplo: "Para ganhar mais dinheiro"

POR QUÊ? (Nível 4)
→ Exemplo: "Para ter segurança financeira"

DESEJO PROFUNDO:
A emoção/valor real
→ Exemplo: "Para provar minha capacidade e ter liberdade"

COPY FOCADA NO DESEJO PROFUNDO:
[Escreva conectando ao nível mais profundo]
```

## Template 10: Análise de Objeções

```
OBJEÇÃO 1: [Ex: "É muito caro"]
CAUSA RAIZ: Não vê valor suficiente
RESPOSTA NA COPY: Ampliar valor percebido, mostrar ROI, comparar com alternativas

OBJEÇÃO 2: [Ex: "Não vai funcionar para mim"]
CAUSA RAIZ: Ceticismo/experiências passadas
RESPOSTA NA COPY: Casos similares, garantia, mecanismo diferente

OBJEÇÃO 3: [Ex: "Não tenho tempo"]
CAUSA RAIZ: Priorização
RESPOSTA NA COPY: Custo de NÃO fazer, simplificação, resultados rápidos

OBJEÇÃO 4: [Ex: "Vou pensar"]
CAUSA RAIZ: Falta de urgência
RESPOSTA NA COPY: Urgência real, custo de espera, bônus limitados
```

## Checklist Final Pré-Publicação

Antes de publicar qualquer copy, verifique:

```
[ ] A headline para a atenção e promete benefício claro?
[ ] A primeira linha faz querer ler a segunda?
[ ] Identifiquei o nível de consciência corretamente?
[ ] Adaptei ao nível de sofisticação do mercado?
[ ] Foquei em DESEJOS, não apenas características?
[ ] Apresentei mecanismo único (se mercado sofisticado)?
[ ] Incluí prova forte e específica?
[ ] Antecipei e respondi objeções principais?
[ ] A oferta é clara e irresistível?
[ ] Há urgência/escassez real (não fabricada)?
[ ] O CTA é óbvio e de baixa fricção?
[ ] Li em voz alta e soa natural?
```

## Fórmulas Rápidas de Schwartz

### Para Headlines

1. **Direto**: [RESULTADO] + [TEMPO] + [QUALIFICADOR]
2. **Curiosidade**: "Por Que [SITUAÇÃO ESTRANHA]"
3. **Notícia**: "Novo/Finalmente/Descoberto: [SOLUÇÃO]"
4. **Pergunta**: "[PROBLEMA ESPECÍFICO]? Aqui Está [SOLUÇÃO]"
5. **Como**: "Como [GRUPO] Consegue [RESULTADO] Sem [OBJEÇÃO]"

### Para Leads

1. **História**: Comece com momento específico
2. **Pergunta**: Faça sentir "ele me entende"
3. **Declaração Ousada**: Afirmação que desafia crença
4. **Estatística Surpreendente**: Número que choca
5. **Cenário**: "Imagine que..."

### Para Calls-to-Action

1. **Comando Direto**: "Clique aqui para..."
2. **Benefício Imediato**: "Sim, quero [BENEFÍCIO]"
3. **Sem Risco**: "Testar sem risco"
4. **Urgência**: "Garantir vaga agora"
5. **Próximo Passo**: "Começar agora"

---

Use estes templates como ponto de partida, mas sempre adapte para:
- Sua voz de marca
- Seu público específico
- O contexto do mercado
- A verdade do seu produto

A melhor copy é autêntica E estratégica.
